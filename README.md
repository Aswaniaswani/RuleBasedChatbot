Rule-Based Chatbot

# Project Description
This project is a simple conversational chatbot developed using Python.

It uses keyword matching and predefined rules to recognize user messages and generate responses.

# Features
* Greeting recognition
* Self-introduction
* Python-related conversations
* Thank you responses
* Goodbye responses
* Fallback responses for unknown questions

# Technologies Used
* Python
* Regular Expressions (Regex)
* Basic NLP concepts

# How to Run
1. Install Python.
2. Open the project folder.
3. Run: python chatbot.py
4. Start chatting with PyBot.

## Conclusion
This project demonstrates basic chatbot development, intent recognition, keyword mapping and response generation using Python.
